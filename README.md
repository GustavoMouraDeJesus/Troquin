# Troquin

**Mudando vidas de troquin em troquin.** 💰📈

## 📌 Sobre o projeto

A **Troquin** é uma **plataforma web** criada com o objetivo de promover **educação financeira acessível** para pessoas de baixa renda, utilizando uma linguagem simples, direta e de fácil entendimento.

O projeto nasceu com o propósito de ajudar pessoas das comunidades a **economizarem dinheiro**, entenderem melhor como organizar suas finanças e darem os primeiros passos no mundo dos investimentos — sempre respeitando a realidade financeira do público.

---

## 🎯 Público-alvo

* Pessoas de **baixa renda**
* Pessoas das **comunidades** que desejam melhorar sua relação com o dinheiro
* Usuários iniciantes em educação financeira

---

## 💡 Ideia principal

Levar **educação financeira de forma simples**, usando palavras fáceis e exemplos práticos, mostrando que é possível mudar de vida começando com pouco.

> **Educação financeira para todos, de troquin em troquin.**

---

## ⚙️ Funcionalidades

* Introdução à **educação financeira básica**
* Conteúdo explicativo sobre:

  * Como começar a investir
  * Organização financeira e impacto nos objetivos pessoais
  * Diferença entre **Tesouro Selic**, **CDB** e **cofrinhos/caixinhas**
* Passo a passo para iniciar nos investimentos
* **Calculadora de juros compostos**
